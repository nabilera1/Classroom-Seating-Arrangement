# 🪑 교실 자리 배치 프로그램

설치나 서버 없이 **브라우저에서 파일 하나만 열면 바로 사용할 수 있는** 교실 자리 배치 웹앱입니다.
학생 명렬을 입력(또는 txt 파일 업로드)하면 자리 수가 자동으로 맞춰지고, 랜덤/순서대로 배치, 담임 선생님 최종 확인, 인쇄까지 한 화면에서 처리할 수 있습니다.

## 🔗 바로 사용하기

설치 없이 아래 링크만 열면 바로 사용할 수 있습니다.

**👉 [교실 자리 배치 프로그램 열기](https://nabilera1.github.io/Classroom-Seating-Arrangement/)**

> GitHub Pages로 배포되어 있으며, 링크는 저장소의 `index.html`을 그대로 보여줍니다. 저장소 이름이나 배포 설정을 바꾸신 경우 이 링크도 함께 업데이트해 주세요.

## ✨ 주요 기능

- **랜덤 자리 배치**: 버튼 클릭 한 번으로 자리마다 이름이 빠르게 바뀌다가 착석하는 애니메이션과 함께 무작위로 배치됩니다.
- **번호 순서대로 배치**: 학생 번호와 자리 번호를 1:1로 맞춰 배치합니다.
- **자리 맞바꾸기**: 자리 두 곳을 순서대로 클릭하면 서로 자리를 바꿀 수 있습니다.
- **자리 번호 / 학생 번호 구분 표시**: 각 좌석 카드에 물리적 위치인 *자리 번호*(왼쪽 위)와 명렬상의 *학생 번호*(오른쪽 위, 배지)가 함께 표시되며, 학생 번호와 이름은 항상 한 세트로 이동합니다.
- **자리 수 자동 조정**:
  - 명렬에 이름이 20번까지만 입력되어 있으면 자리도 20개만 생성됩니다.
  - 중간 번호가 비어 있는 경우(예: 22번이 전학/자퇴 등으로 빠지고 25번까지 있는 경우)에도 마지막 입력 번호(25번)까지 자리 수를 맞추고, 빈 번호는 빈 자리로 표시합니다.
- **학생 명렬 입력/수정**: 오른쪽 패널에서 1번부터 이름을 직접 입력하거나 수정할 수 있습니다.
- **txt 파일 업로드**: 한 줄에 한 명씩 이름이 적힌 `.txt` 파일을 업로드하면 명렬이 자동으로 채워집니다 (앞에 붙은 번호 표기는 자동 제거).
- **학생명렬.txt 자동 불러오기**: `index.html`과 같은 위치에 `학생명렬.txt` 파일이 있으면 페이지를 열 때 자동으로 명렬을 채웁니다. 파일이 없으면(또는 `file://`로 직접 열어 브라우저가 파일 읽기를 막는 경우) 조용히 무시되고 평소처럼 빈 명렬 상태로 시작합니다.
- **짝꿍 / 분리 배치 태그**: 이름 뒤에 숫자를 붙이면 랜덤 배치 시 반영됩니다.
  - `0~9`: 같은 숫자를 가진 학생끼리 같은 책상(짝)으로 배치 (예: `홍길동1`, `유관순1` → 항상 짝)
  - `11~99`: 같은 숫자를 가진 학생끼리 같은 책상에 배치되지 않도록 분리 (예: `김철수11`, `노영심11` → 항상 떨어져 앉음)
  - 이름 표시 자체는 바뀌지 않고, 숫자는 배치 규칙 판단에만 사용됩니다.
- **학년 / 반, 담임 선생님 성함, 학교명 입력**: 자리 배치표 상단에 학년·반을 입력할 수 있고, 최종 확인 버튼에 표시되는 담임 선생님 성함, 화면 맨 아래 학교명(기본값: 김해수남고등학교)도 직접 수정할 수 있습니다.
- **영어 명언/속담 배너**: 화면 상단 중앙에 영어 명언·속담이 랜덤으로 표시되며, 새로고침 버튼으로 다른 문구를 볼 수 있습니다.
- **최종 확인 → 인쇄**: 담임 선생님이 "최종 확인" 버튼을 누르면 배치가 잠기고(수정 불가), 인쇄 버튼이 나타납니다. 인쇄 시에는 명언, 학년/반, 자리 배치도, 확인 도장만 출력되고 편집용 버튼·명렬 패널은 자동으로 숨겨집니다.
- **잠금 해제**: 최종 확인 후에도 실수했을 경우 잠금을 해제하고 다시 수정할 수 있습니다.

## 🚀 사용 방법

1. [바로 사용하기](https://nabilera1.github.io/Classroom-Seating-Arrangement/) 링크로 접속하거나, `index.html` 파일을 다운로드해 더블클릭(또는 브라우저로 열기)해서 실행합니다. 별도 설치나 인터넷 연결이 필요 없습니다.
2. 화면 위쪽에서 **학년 / 반**을 입력합니다.
3. 오른쪽 **학생 명렬** 패널에서 학생 이름을 1번부터 순서대로 입력합니다.
   - 직접 입력하거나,
   - `📂 txt 파일 업로드` 버튼으로 한 줄에 한 명씩 적힌 `.txt` 파일을 불러올 수 있습니다. (샘플 파일: `학생명렬.txt`)
   - `✨ 예시 이름 채우기` 버튼으로 임의의 이름 30명을 채워 테스트해볼 수 있습니다.
4. 왼쪽 자리 배치도에서 **🎲 랜덤으로 섞기** 또는 **🔢 번호 순서대로** 버튼으로 자리를 배치합니다.
   - 마음에 드는 조합이 나올 때까지 랜덤 배치를 여러 번 눌러도 됩니다.
   - 자리 두 곳을 클릭하면 두 학생의 자리를 서로 바꿀 수 있습니다.
5. **담임 선생님 성함**을 확인/수정한 뒤 **✅ (성함) 선생님 최종 확인** 버튼을 누르고, 확인 창에서 다시 한 번 확정합니다.
6. 최종 확인이 끝나면 **🖨️ 인쇄하기** 버튼이 나타납니다. 클릭하면 브라우저 인쇄 대화상자가 열리고, 자리 배치도 부분만 깔끔하게 인쇄(또는 PDF로 저장)됩니다.
7. 실수로 확정했다면 **🔓 잠금 해제하고 다시 수정하기**를 눌러 다시 배치할 수 있습니다.

## 📋 자리 수 결정 규칙

자리 배치도의 좌석 수는 **학생 명렬에서 이름이 입력된 마지막 번호**를 기준으로 자동 결정됩니다.

| 명렬 입력 상태 | 생성되는 자리 수 |
|---|---|
| 1~20번까지만 이름 입력 | 20개 |
| 1~21번, 23~25번 입력 (22번만 공백) | 25개 (22번 자리는 빈 자리로 표시) |
| 전체 입력 없음 | 0개 (안내 문구 표시) |

즉, 중간에 빠진 번호는 전학·자퇴 등으로 결번된 것으로 간주하여 해당 자리는 비워두되, 전체 자리 수 계산에는 포함됩니다.

## 🔗 짝꿍 / 분리 배치 규칙

명렬에 이름을 입력할 때(직접 입력, txt 업로드 모두 동일) 이름 뒤에 숫자를 붙이면 **🎲 랜덤으로 섞기**를 실행할 때 아래 규칙이 적용됩니다. (**🔢 번호 순서대로** 배치에는 적용되지 않습니다.)

| 숫자 범위 | 규칙 | 예시 |
|---|---|---|
| `0~9` | 같은 숫자를 가진 학생끼리 같은 책상(짝)으로 배치 | `홍길동1`, `유관순1` → 항상 짝 |
| `11~99` | 같은 숫자를 가진 학생끼리 같은 책상에 배치되지 않도록 분리 | `김철수11`, `노영심11` → 항상 떨어져 앉음 |
| 숫자 없음 (또는 `10`) | 규칙 없이 무작위 배치 | — |

- 같은 숫자를 가진 학생이 정확히 2명일 때만 규칙이 확실하게 지켜집니다. 3명 이상이 같은 숫자를 쓰면 정확히 짝을 지을 수 없어 일반 학생으로 처리됩니다.
- 이름 자체는 화면에 입력한 그대로(숫자 포함) 표시되며, 숫자는 배치 계산에만 쓰입니다.
- "책상"은 화면상 나란히 붙어 있는 두 자리(예: 1번·2번)를 뜻합니다.

## 📥 학생명렬.txt 자동 불러오기

저장소(또는 배포 폴더)에 `index.html`과 같은 위치에 `학생명렬.txt` 파일을 두면, 페이지를 열 때 자동으로 명렬을 채워줍니다.

- **GitHub Pages로 접속한 경우**: `학생명렬.txt`가 저장소에 함께 커밋되어 있으면 정상적으로 자동 로딩됩니다.
- **`index.html`을 로컬 파일(file://)로 더블클릭해서 연 경우**: 브라우저 보안 정책상 로컬 파일을 자동으로 읽어올 수 없어 자동 불러오기가 동작하지 않습니다. 이 경우 `📂 txt 파일 업로드` 버튼으로 수동으로 불러오면 됩니다.
- 파일이 아예 없는 경우에는 조용히 무시되고, 기존처럼 빈 명렬 상태로 시작합니다(오류 메시지 없음).
- 매 학기 명렬이 바뀐다면, 저장소의 `학생명렬.txt` 내용만 새 명단으로 교체해 커밋하면 다음에 페이지를 열 때부터 자동으로 반영됩니다.

## 🗂 파일 구성

```
index.html               # 메인 프로그램 (이 파일만 있으면 실행 가능, GitHub Pages 배포 시 루트 주소로 자동 서빙)
학생명렬.txt              # 업로드 테스트용 샘플 명렬 (임의의 이름 30명)
README.md                # 이 문서
```

## 🎨 커스터마이징 팁

파일을 텍스트 에디터로 열면 아래 부분을 쉽게 수정할 수 있습니다.

- **좌석 배치 구조(그룹/열 수)**: `<script>` 안 `buildSeatChart()` 함수의 `rowCount`, 그룹 관련 로직
- **교탁/교사 책상 위치 라벨**: `GROUP_LABELS` 배열
- **영어 명언 목록**: `quotes` 배열에 `[본문, 저자]` 형태로 추가/수정
- **색상 테마**: `<style>` 상단 `:root` 안의 `--grad1`, `--grad2`, `--accent` 등 CSS 변수
- **최대 인원수(현재 30명)**: `SEAT_COUNT` 상수

## 🌐 브라우저 호환성

최신 Chrome, Edge, Safari, Firefox 등 대부분의 데스크톱 브라우저에서 정상 동작합니다. 별도의 서버나 인터넷 연결 없이 파일만으로 완전히 동작하는 단일 HTML 파일입니다 (데이터는 저장되지 않고 브라우저를 새로고침하면 초기화됩니다).

## 📦 직접 배포하기 (GitHub Pages)

이 저장소를 포크하거나 그대로 사용해 자신의 GitHub Pages로 배포하려면:

1. 저장소 **Settings → Pages**로 이동합니다.
2. Source를 **Deploy from a branch**로 설정하고, Branch는 `main`, 폴더는 `/ (root)`를 선택한 뒤 저장합니다.
3. 잠시 후 `https://<본인계정>.github.io/<저장소이름>/` 주소가 생성되며, 저장소 루트의 `index.html`이 자동으로 보여집니다.

리포지토리는 GitHub Pages를 사용하려면(무료 개인 계정 기준) **Public**이어야 합니다.
